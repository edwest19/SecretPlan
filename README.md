# SecretPlan

A free, open-source Medicare Part D plan comparison prompt. 

Generic Medicare Part D plan comparison and analysis prompt for AI.

The goal is to help people evaluate Medicare prescription drug plans using documented, evidence-based research rather than advertisements or incomplete cost comparisons.

## Features

- Compare Medicare Part D plans
- Compare pharmacy costs
- Compare formularies
- Compare mail-order options
- Assess future medication flexibility
- Compare cash-pay alternatives
- Cite official sources

## Privacy

Never enter:
- Medicare numbers
- Social Security numbers
- Full dates of birth

ZIP code, age, and medication information are usually sufficient for plan analysis.
